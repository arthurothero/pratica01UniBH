# Prática 01 — Introdução ao HTML e CSS

Exercícios introdutórios sobre a estrutura de páginas HTML e aplicação de estilos com CSS.

## Conteúdos praticados

- Estrutura básica de um documento HTML
- Títulos utilizando as tags `<h1>` e `<h2>`
- Estilização inline com o atributo `style`
- Estilização interna utilizando a tag `<style>`
- Estilização externa utilizando um arquivo CSS
- Alteração de cor, tamanho, fonte, alinhamento e margem

## Exercícios

| Exercício | Descrição |
|---|---|
| `pratica01e01.html` | Criação de uma página HTML básica com título e subtítulo |
| `pratica01e02.html` | Aplicação de estilos diretamente no elemento HTML |
| `pratica01e03.html` | Aplicação de CSS interno utilizando a tag `<style>` |
| `pratica01e04.html` | Aplicação de CSS externo através do arquivo `pratica01e04.css` |

## Como executar

1. Baixe ou clone este repositório.
2. Acesse a pasta `pratica01`.
3. Abra qualquer arquivo `.html` em um navegador.
